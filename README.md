# Заначка

Приложение для учёта доходов и расходов, чтобы откладывать больше. Работает на телефоне как обычное приложение, без интернета и без регистрации.

**Открыть:** https://crystal-io.github.io/zanachka/

## Что умеет

- Счета в виде банкнот: карта, наличные, накопления, счёт в банке. Цвета взяты из серии банкнот евро.
- Запись расхода за пару касаний: своя цифровая клавиатура, частые категории идут первыми, счёт подставляется сам.
- Переводы между счетами, например в накопления.
- Обзор месяца: сколько отложено и какая это доля дохода, куда ушли деньги.
- История с фильтрами и поиском, правка и удаление операций.
- Резервная копия в файл и восстановление из него.
- Светлая и тёмная тема (как в системе).

## Как установить на Android

1. Откройте ссылку выше в Chrome.
2. Нажмите ⋮ (меню справа сверху) → **Установить приложение** (или **Добавить на главный экран**).
3. Иконка появится на главном экране. Если нажать на неё и подержать, появятся ярлыки «Расход» и «Доход».

## Где хранятся данные

Только на вашем телефоне, в памяти браузера (IndexedDB). На сервер ничего не отправляется. Чтобы не потерять данные вместе с телефоном, раз в неделю сохраняйте резервную копию: **Ещё → Сохранить копию**. Файл можно перенести в Google Диск.

## Разработка

Нужен Node.js 22+.

```bash
npm install
npm run dev      # сервер разработки
npm run build    # проверка типов и сборка в dist/
npm run preview  # просмотр собранной версии
npm run icons    # перегенерировать иконки в public/
```

Стек: Vite, React, TypeScript, Dexie (IndexedDB), vite-plugin-pwa.

Каждый push в `main` автоматически публикуется на GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`).
